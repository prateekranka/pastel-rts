# Pastel RTS

A touch-first science-fantasy real-time strategy game for iPad.

The first playable biome is **Alien Fantasy**: clean teal terrain, oversized alien flora, crystal resources, spatial magic, gravity weapons, and two visually distinct civilizations.

## Current milestone

**Milestone 0 — platform and 60 FPS proof**

- TypeScript + Three.js match runtime
- Fixed isometric orthographic camera
- 160 × 160 logical map split into 16 × 16 chunks
- Pointer-based touch pan and pinch zoom
- 70-percent default camera preset
- High-entity-count stress scene
- WebGL and experimental WebGPU benchmark paths
- Performance HUD and soak-test reporting
- Minimal SwiftUI + WKWebView iPad shell

Final units, buildings, economy, combat, AI, and multiplayer are intentionally outside this milestone.
