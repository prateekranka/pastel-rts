## Root cause and bounded fix

The runtime contract requires explicit `?content=studio` for development content. The existing launcher already printed that explicit studio query, so Foundry publication was not disconnected in the primary URL.

The launcher did not print a usable bundled/offline game preview. It printed only the bundled pack file path under the label `Fixture`. The owned script now prints both routes:

- `Studio game: http://127.0.0.1:<game-port>/?mode=interaction-lab&content=studio`
- `Bundled/offline: http://127.0.0.1:<game-port>/?mode=interaction-lab`

The normal runtime default remains bundled content. `parseRuntimeConfig()` still maps every query other than `content=studio` to `content: 'bundle'`. The Foundry sandbox builder still adds `mode=interaction-lab&content=studio`, the scenario, seed, revision, and selected stable ID.

`scripts/sync-web-build.mjs` was not changed. The production build already copied `content/dev-pack-v2` into `apps/game-web/dist` and used relative base paths.
