Existing APIs in M1.1-A-handoff are authoritative. Wave 2 adds these coordinator-defined interfaces, owned solely by backend lane A2:

GET /v2/revisions/:revision/pack returns immutable PackV2. GET /v2/revisions/:revision/assets/<logical asset path> returns only assets listed in that revision metadata, including map/scenario data. No arbitrary local path resolution. Client base for historical pack assets is /dev-content/v2/revisions/:revision/assets/.
GET /v2/draft/pack returns draft PackV2. GET /v2/draft/assets/<logical path> returns only assets referenced by draft, for editor preview.
GET /v2/references/:id/image returns that attachment PNG, never part of runtime pack.
POST /v2/acknowledgements accepts {runtimeId, scenarioId, revision, simulationRulesHash, restartRequired}. Validate bounded IDs, revision exists and hash equals that revision metadata. GET returns {acknowledgements:[{runtimeId,scenarioId,revision,simulationRulesHash,restartRequired,updatedAt}]}. Bounded volatile status (max 32 entries), not simulation state or durable gameplay truth.
POST /v2/validate accepts {expectedDraftRevision}, validates current draft without publishing, returns {ok:true,draftRevision}. Failure leaves published state unchanged.
