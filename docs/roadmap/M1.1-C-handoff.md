Source findings for later Luna tickets

1. Missing original art fixtures

Evidence: content/dev-pack-v2/pack.json references unit and building PNG paths. The worktree inventory contained only JSON files under content/dev-pack-v2. The existing fallback is in apps/game-web/src/sandbox/animation/spriteAtlas.ts, lines 97-125.

Minimal later fix: integrate the original fixture pack under the owner lane. Keep missing assets as a visible failed condition. Do not label generated placeholders as complete art.

2. V2 hot reload reads the bundled pack

Evidence: apps/game-web/src/content/ContentHotReload.ts, lines 50-60, sends V2 events to GameApp. apps/game-web/src/app/GameApp.ts, lines 446-455, calls refreshLabPack. loadPackV2 at lines 482-488 reads packV2PublicBaseUrl(), which is the static bundled content path, not /dev-content/pack?schema=2.

Minimal later fix: make the development reload path read the isolated content-server Pack v2 and refresh the runtime archetype/palette references. Keep production on relative bundled paths. Preserve the dev-only EventSource guard.

3. Accepted building is not visible in public pickable readback

Evidence: the isolated blocker audit recorded an accepted placement and changed nav paths, but getPickableEntities() still returned the original building count. Relevant source is apps/game-web/src/sandbox/createInteractionLab.ts, lines 171-187 and 334-360, plus the interaction worker snapshot path.

Minimal later fix: trace the accepted building ID from the worker result through the snapshot and registry. Make the public readback and building render path agree. Do not make the audit count a substitute for authoritative state.

4. Replay mismatch after a live blocker sequence

Evidence: the public ReplayInspector returned false after the blocker command sequence. Relevant source is apps/game-web/src/sandbox/ScenarioController.ts, lines 111-145, and apps/game-web/src/sandbox/replay/CommandRecorder.ts, lines 75-88.

Minimal later fix: compare the saved command log, accepted results, replay tick bound, and checksum list at the first divergent tick. Keep deterministic replay and save metadata aligned. Do not loosen checksum assertions.

5. Foundry sprite-sheet controls do not produce the expected manifest

Evidence: the audit set the explicit horizontal sheet controls but the manifest still reported a 128-pixel frame width. Relevant source is apps/foundry/src/unit/unitEditor.ts, lines 126-140 and 223-260.

Minimal later fix: reproduce the event ordering between PNG inference and explicit sheet edits. Ensure the selected sheet layout is the single source for frame dimensions before validation and save. Preserve the single-PNG path.

6. Existing native pause regression

Evidence: the existing battlefield suite received a 7-tick delta during the 600 ms pause window. Relevant source is apps/game-web/src/app/GameApp.ts pause/resume and the benchmark SimClient worker path.

Minimal later fix: isolate whether the native message arrives after the sampled baseline or whether the worker interval continues after pause. Keep the no-fast-forward invariant. Do not change the assertion threshold.
