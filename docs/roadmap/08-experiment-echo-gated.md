# E1 — Optional narrow Echo experiment, not a launch requirement

Read and apply docs/roadmap/00-astra-luna-contract.md. Execute only after explicit approval of this experiment. Astra orchestrates/reviews; Luna Max Fast implements.

GOAL
Test one comprehensible temporal ability, not army-wide macros, timeline editing or a replayed match pretending to be a live ability.

Implement one chosen chimera ability that leaves a visible trail. After an authored delay, one clearly spectral echo repeats that single attack along the trail. It must present a real, avoidable threat—not depend on opponents mistaking it for a normal army.

Define how current terrain, fold transitions, new obstacles, dead targets and interrupted casts affect it. The simplest policy is to validate the stored path against current legal geometry and stop at a new blocker. Show the cancelled/shortened result. Do not teleport through a newly disconnected crossing to preserve an old recording.

Echoes cannot gather, capture, construct, fuse or create more echoes. Bound count/lifetime and define damage, friendly fire, cost and source-death behaviour. Store the necessary historical action data explicitly in saves/checksums; do not read render frames as authority.

TOOLS
An Echo timing strip in the Ability Editor: delay, lifetime, effect scale, path policy and telegraph. A trail inspector shows stored versus currently valid path. Include source action, echo resolution, blocked-path and folded-region test presets.

LUNA TASKS
A: deterministic historical-action record and resolver.
B: spectral rendering, telegraph and editor timing strip.
C: adverse topology/death/replay tests and comparison scenarios.

ACCEPTANCE
Change delay and strength through Foundry and replay the case. Test replay determinism, capped entities, source death and prevention of recursive casts. Human gate: do players recognise and counter the echo without reading a long tutorial? Deliver retain/revise/drop evidence. Keep it disabled by default until accepted; do not make this experiment a prerequisite for multiplayer.
