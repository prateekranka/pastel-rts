## Change

`projectGroundRadius` now returns the exact horizontal and vertical screen extents of the projected world ground circle.

- It converts the input radius from cells to world units with `CELL_SIZE`.
- It projects the world-X and world-Z radius vectors through the actual `IsometricCamera`.
- It computes screen X as `hypot(worldXScreenX, worldZScreenX)`.
- It computes screen Y as `hypot(worldXScreenY, worldZScreenY)`.
- It does not use the full length of one projected world edge as an ellipse radius.
- The existing `ProjectedGroundRadius` consumer contract is unchanged.

## Tests

`apps/foundry/src/previewProjection.test.ts` now samples 8,192 points on the world ground circle and compares the observable projected extrema with the returned `radiusX` and `radiusY`.

Coverage includes:

- gameplay/default zoom at viewport `320x220`;
- explicit `70-percent` zoom at viewport `640x360`;
- different viewport aspect ratios;
- cell-to-world conversion through the runtime `CELL_SIZE` constant.

The prior symmetric-circle implementation was checked against the new test. It failed both sampled cases:

- `320x220`: returned `5.51934662919109`, sampled `6.75979147753435`, difference `1.2404448483432597`;
- `640x360`: returned `9.947784167473046`, sampled `12.183497640823362`, difference `2.235713473350316`.

The test precision was not loosened. The expected difference threshold was `0.000005` at five decimal places.
