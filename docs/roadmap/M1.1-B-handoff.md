Commands

Generate and validate the source pack:

```text
npm run fixture:generate
npm run content:validate -- --pack-dir /home/bobbyranka/Projects/pastel-rts-m11-fixtures/content/dev-pack-v2
```

The validator accepts `--pack-dir <dir>` or a positional directory. It validates Pack v2 with the existing schema, verifies contentHash, resolves maps and scenarios, checks archetype dependencies, decodes PNG chunks and scanlines, checks actual dimensions, and compares move-frame pixels.

Validator limits:

- 256 files per selected pack
- 16 MiB total selected-pack bytes
- 512 KiB `pack.json`
- 2 MiB map/scenario JSON document
- 2 MiB per PNG
- 2048px maximum PNG width or height
- 1,048,576 maximum decoded pixels

The validator rejects missing files, corrupt PNG signatures/chunks/CRC/deflate/scanlines, unsafe relative paths, symlinks, path escapes, invalid clips, missing frame indexes, duplicate references, bad map/scenario dependencies, and non-proxy units without distinct move frames. Errors return exit code 1 and print the failing path or reference.

Verified invalid isolated copies:

- Removed `sunweaver-scout/sheet.png`: validator exit `1`.
- Truncated `gravemark-stalker/sheet.png`: validator exit `1`.
- Traversal mutation in an isolated pack: validator exit `1` before any outside file read.
