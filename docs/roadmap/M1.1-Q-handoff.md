## Art readiness helper note

The temporary helper timed out because it used the wrong diagnostics shape. The
actual captured runtime value is not missing art:

```text
runtime.art.unit = { assets: [...], loadedTextures: 4 }
runtime.art.building = [ ... ]
```

The helper treated `runtime.art.unit` as an array and checked
`unit.length > 0 && unit.every(...)`. The actual unit value is an object with
an `assets` array. It has no array `length` value for that check. The building
value is the array shape.

The raw baseline and final captures show all four unit asset entries with
`state="ready"` and `error=null`, plus all three building entries with
`state="ready"` and `error=null`. They also report
`missingUnitAssets=0`, `missingBuildingAssets=0`, and runtime `error=null`.
Therefore the helper timeout is a temporary probe shape error. It is not
missing runtime art. The temporary probe is not a committed product or test
file.
