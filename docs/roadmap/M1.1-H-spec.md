## Runtime invariants

1. Bundle mode is the default and is offline. It reads the relative bundled Pack v2 and does not construct EventSource or request /dev-content.
2. Studio mode is explicit. It reads publication status, selected immutable revision metadata, and that revision Pack v2. It uses only the revision asset prefix.
3. A studio candidate is accepted only after HTTP success, validated metadata, validated Pack v2, equal revision, equal pack id, equal canonical content hash, equal visual hash, equal simulation-rules hash, and an exact metadata asset-path identity check.
4. A request generation, install generation, and disposal check prevent an older or disposed asynchronous operation from becoming active.
5. A cosmetic replacement keeps the worker and current scenario. It changes the content and asset identity only after the renderer transaction succeeds. A post-install hook acknowledges the exact newly active revision.
6. A simulation-rules replacement enters restart-required. It does not mutate the active match. The explicit restart action installs the pending revision, reloads the selected scenario from tick zero, and acknowledges that exact revision with restartRequired true before reporting success.
7. Historical revision selection pins the revision. Publication events and reconnects report newer availability and never silently switch the selected match.
8. Failed publication, failed candidate load, failed renderer transaction, failed restart, and failed acknowledgement leave the last active content and match usable. The failure includes the requested revision or operation.
9. Runtime query identifiers use bounded safe values. Foundry launcher values preserve the exact scenario, seed, and requested spawn ID. Unit spawn is issued after the requested scenario is loaded; building spawn enters placement for the requested building.
10. Same-seed A/B replay uses the same scenario, map, and command log. Equal commands produce equal checksums. A rules change is a distinct valid outcome and is not reported as an equality failure.

## Evidence contract

It runs with game port 22373, Foundry port 22374, and content port 22387. It captures composited screenshots at 1280x800 and 1194x834, browser console errors, request failures, content requests, asset requests, runtime resource counts, and frame/performance diagnostics. Chromium may use the configured installed executable and ignoreDefaultArgs=--disable-dev-shm-usage only. No --no-sandbox or unsafe rendering switch is accepted. SwiftShader/Linux results are labelled as desktop evidence, not physical-device proof.

The existing visual threshold remains unchanged. A snapshot update is allowed only after the actual and expected captures show the mismatch is a deliberate E UI/art change with no camera, terrain, entity, geometry, input, or asset-loading regression.
