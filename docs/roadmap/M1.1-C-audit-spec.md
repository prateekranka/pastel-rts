Isolation contract

- Game server: 127.0.0.1:14373.
- Foundry server: 127.0.0.1:14374.
- Content server: 127.0.0.1:14387.
- Pack writes: /tmp/pastel-rts-m11-c-pack.
- Port 127.0.0.1:8787 is never used, changed, or stopped.
- Vite configuration is unchanged. A Playwright route handler is the test-scoped reverse proxy from /dev-content to 127.0.0.1:14387. The isolated configuration sets VITE_GAME_WEB_ORIGIN to http://127.0.0.1:14373 so Test in Sandbox reaches the isolated game.
- Development runs use PLAYWRIGHT_SERVER_MODE=dev. Offline production runs use PLAYWRIGHT_SERVER_MODE=preview and PLAYWRIGHT_SKIP_CONTENT_SERVER=1.
- Chromium runs use PLAYWRIGHT_CHROMIUM_PATH=/usr/bin/chromium and PLAYWRIGHT_IGNORE_DEFAULT_ARGS=--disable-dev-shm-usage on this host. No sandbox, web-security, or other security control is disabled.
- Default Playwright behavior remains 4173, 4174, 8787, preview servers, and the bundled browser when the override variables are absent.

Evidence contract

Each audit capture is a composited page screenshot from page.screenshot(), never WebGL readPixels. A JSON sidecar records URL, canvas dimensions, runtime markers, console messages, page errors, failed requests, HTTP error responses, and the stage metadata. Missing PNG assets, disconnected sandbox content, and unsupported save/load UI are findings, not hidden failures.

Acceptance

- The isolated configuration starts the three required services without touching port 8787.
- Existing game and Foundry suites run against the isolated ports. Root failures remain visible.
- New audit evidence contains real screenshots and browser diagnostics for every verification surface.
- Test assertions check observable behavior. They do not loosen visual thresholds or rewrite snapshots.
- The handoff names exact source locations, reproduction steps, evidence paths, CPU/SwiftShader limitations, and later Luna tickets.
- No runtime or product implementation is fixed in this worktree.
